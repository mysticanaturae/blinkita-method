\# Research Approach



This repository documents the development of a methodology while it is being created.



The goal is not to present a finished theory.



The goal is to preserve:



\- decisions

\- experiments

\- iterations

\- discoveries

\- improvements



so the evolution of the methodology remains transparent.



\---



\# First Principle



A Living World is not created once.



It is designed, developed, observed and continuously evolved.



The BLINKITA METHOD™ explores the processes behind creating such evolving systems.
