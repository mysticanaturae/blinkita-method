\# What Is BLINKITA METHOD™?



BLINKITA METHOD™ is an evolving methodology for creating Living Worlds™.



It explores how creators can transform:



Possibility



↓



Vision



↓



Structure



↓



Creation



↓



Experience



↓



Memory



↓



Evolution



↓



Continuity





The methodology is independent from BLINKITA OS™.



BLINKITA OS™ represents one digital implementation of the methodology.
